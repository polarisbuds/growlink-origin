## TeamUp ライク基本機能：未掲載・未実装に感じるもの

1on1 面談ツールとして一般的だが、現行 er.md / statedisplaytransition.md / Entity に薄い、または無い機能。  
**今は実装しなくてよいか** を確認する。

| ID | 機能 | 現状 | 現行モデルへの組み込み案 |
| --- | --- | --- | --- |
| T01 | 実施リマインド通知 | なし | `histories.event_type` に `meeting.remind` を追加。または users / 管理設定に通知 ON/OFF 列 |
| T02 | 定期ミーティング自動作成 | 管理設定タブに注記のみ。Entity なし | `system_settings` テーブル、または meetings を cron で生成（template_id + pairing_id + implemented_at） |
| T03 | ホーム画面の面談サマリ | 遷移図に home のみ。集計定義なし | 新テーブル不要。meetings.status + pairings で一覧 API |
| T04 | メンターによるペア解消 | usecase に pairing 操作あり。画面/API 薄い | 既存 pairings の論理削除（deleted_at）で足りる |
| T05 | 進捗ダッシュボード | progress 画面は検索・切替のみ | meetings.status を department / team / pairing 単位で集計。新テーブル不要 |
| T06 | テンプレート複数・デフォルト指定 | templates は CRUD あり | templates に `is_default` 列、または管理設定で default_template_id FK |
| T07 | 面談の「完了」承認フロー | submitted / done のみ | done を mentee 提出・mentor 確認の二段階にするなら status VO を拡張 |
| T08 | 監査ログのエクスポート | mng_setting_log_tab にファイル取得の注記 | histories を CSV 出力。または別 `audit_logs` は必須ではない |
| T09 | チーム / SM 単位の一括ペア登録 | ペアリング部署編集画面に注記 | 既存 teams / team_members / pairings の bulk insert usecase |
