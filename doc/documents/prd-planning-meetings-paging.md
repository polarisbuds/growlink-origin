# PRD: 面談一覧のページング

対象画面は組織内の面談一覧（`/planning/meetings`）だけとする。ペア一覧は対象外。

## 背景

面談一覧は `GET /api/v1/meetings/all` が権限内の面談を全件返し、絞り込みと並び替えを画面側で全件に対して行っている。件数が多いときに、表示に必要な分だけを取り、隣のページは先に用意しておきたい。

## ゴール

- 一覧はページ単位で取得し、画面にはそのページの行だけを出す。
- 開いたページはすぐ表示し、その前後のページを裏で取得する。
- 実施日の昇順・降順だけをサーバの並び順にする。
- それ以外の列の並び替えは、いま開いているページの行だけに適用する。
- メンター、メンティ、部署、状態、実施日の範囲は、ページを切る前にサーバで絞り込む。

## ページの取り方

1ページの件数は 20 件。ページ番号は 1 から始まる。

画面が保持するのは、表示中のページと、その直前・直後のページだけである。

| 操作 | 画面 | 取得するページ |
| --- | --- | --- |
| 初期表示 | 1ページ目 | 1 と 2 |
| 2ページ目を開く | キャッシュにあれば 2 ページ目をすぐ表示 | 裏で 1 と 3 |
| 3ページ目を開く | キャッシュにあれば 3 ページ目をすぐ表示 | 裏で 2 と 4 |

- 表示しようとしたページが未取得のときは、そのページの取得が終わってから表示する。その後に前後を取る。
- 前後を取るとき、1 より小さいページと、最終ページより大きいページは取らない。
- 窓の外のページは捨てる。表示が 3 ページ目なら 1 ページ目は持たない。
- キャッシュ済みの前後は、ページを開くたびに取り直す。
- 絞り込み、または実施日の昇降順が変わったら、キャッシュを捨てて 1 ページ目に戻し、1 と 2 を取り直す。遅れて届いた古い応答は表示に使わない。

## 並び替え

- 実施日の列を押すと `dir` を `asc` と `desc` で反転し、サーバから取り直す。初期値は `desc`（実施日が新しい順）。実施日が同じ面談は ID の降順で安定させる。
- 部署、メンター、メンティ、テンプレート、状態の列は、表示中ページの行だけを並べ替える。サーバには送らない。
- ページを移ると、新しいページは実施日順で届く。画面側の列並びが選ばれていれば、その並びを新しいページの行にだけ掛ける。ページをまたいだ全体の順序にはしない。

## 絞り込み

次の条件はサーバがページを切る前に適用する。画面のフィルタはそのまま使い、条件が変わるたびに 1 ページ目から取り直す。

- メンター（複数）
- メンティ（複数）
- 部署（複数）。メンターまたはメンティのいずれかが、選ばれた部署に所属していれば残す
- 状態（未着手 / 下書き / 完了）
- 実施日（から / まで）。日付は `YYYY-MM-DD`。から はその日の始まり以降、まで はその日の終わり以前。境界は JST

部署名の表示は、今どおりディレクトリの所属名を画面で引く。

## API

`GET /api/v1/meetings/all`

クエリ:

- `page` : 既定 1
- `pageSize` : 20。これ以外を指定しても 20 として扱う
- `dir` : `asc` または `desc`。既定 `desc`。それ以外は 400
- `mentorUuids` : カンマ区切りのユーザー UUID
- `menteeUuids` : カンマ区切りのユーザー UUID
- `departmentUuids` : カンマ区切りの部署 UUID
- `status` : 面談状態
- `from` / `to` : `YYYY-MM-DD`

応答:

```json
{
  "items": [],
  "total": 123,
  "page": 2,
  "pageSize": 20
}
```

`items` はその条件・実施日順での 1 ページ分。`total` は絞り込み後の件数。指定ページが範囲外のときは `items` は空で、`total` は正しい件数を返す。

見える面談の範囲は今の権限判定と同じとする。取得後に絞り込み、実施日順、スライスを行い、クライアントへ返すのは 1 ページ分だけとする。`POST /api/v1/meetings/all` は変えない。

## 画面

- 表の本体は表示中ページの行だけ。
- 0 件のときは、今と同じ「該当する面談がありません」。
- 表の下に、前へ、ページ番号、次へ、総件数を出す。

## 対象外

- ペア一覧のページング
- 実施日以外の列を、全ページを通した順序にすること
- データベースの `LIMIT` による取得への置き換え
